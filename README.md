# Fenil Sojitra — Creative Developer Portfolio

A colorful, interactive, modern personal portfolio website showcasing Python development, Machine Learning engineering, and creative web experiences.

## ✨ Features
- **Site-Wide AI Neural Constellation Animation**: Interactive background canvas with dynamic particle network and cursor tracking.
- **Interactive ML Playground Canvas**: Interactive linear regression simulator with loss calculations and polynomial fitting.
- **3D Card Tilts & Glare FX**: Holographic cursor-following perspective tilts and reflections.
- **Interactive Terminal REPL**: Simulated CLI environment with custom executable commands and easter eggs.
- **Magnetic Buttons & Draggable Stickers**: Physics-enabled UI components.
- **Fully Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports.

## 🚀 Getting Started
Simply open `index.html` in any modern web browser or serve it via a local static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node / npx
npx serve
```

## 🛠️ Built With
- **HTML5 & CSS3** (Vanilla CSS with Custom Properties, CSS Grid, Flexbox, Keyframe Animations)
- **Vanilla JavaScript** (Canvas 2D API, IntersectionObserver, RequestAnimationFrame)
- **Space Grotesk & Inter** (Google Fonts)
